Installation

Install BitsyJS from npm if your project already uses a package manager, or import the browser build from a CDN without installing anything.

Requirements#

BitsyJS needs a modern browser with support for ES modules, Proxy, WeakMap, fetch, DOMParser, and <template>. Use a local HTTP server during development instead of opening the page as a file:// URL. This lets the browser load local modules and fetch fragments.

CDN#

Import the browser build from jsDelivr. Pin the version in the URL so a new release does not change the code your page loads.

<script type="module">
    const bitsyCdn = "{cdn}";
    const { BitsyJS, signal } = await import(bitsyCdn);

    const count = signal(0);
    const bitsy = new BitsyJS({ data: { count } });
    await bitsy.run();
</script>

If you know the URL up front, you can import the module directly instead of calling import() at runtime.

<script type="module">
    import { BitsyJS } from "{cdn}";

    const bitsy = new BitsyJS();
    await bitsy.run();
</script>

npm#

npm install @im4all/bitsy-js

Import from @im4all/bitsy-js for the source module, or from @im4all/bitsy-js/min for the minified browser build. Both provide named exports. 

// Readable ES module, best with a bundler or dev server
import { BitsyJS, computed, effect, signal } from "@im4all/bitsy-js";

Both entry points export the class and the same reactivity helpers:

Export What it is
BitsyJS The view class. Construct it with settings and call run().
signal Creates a reactive value. Call it to read, set/update to write.
computed Creates a read-only value derived from other signals.
effect Runs a side effect now and again when the signals it reads change.
isSignal Returns true for a signal or computed value created by this module.

Run BitsyJS#

Construct the instance with the data the page needs, then run it once after the DOM is available.

<div b-data>
    <h1>{title}</h1>
    <p b-if="online">Online</p>
</div>

<script type="module">
    import { BitsyJS } from "./bitsy.min.js";

    const bitsy = new BitsyJS({
        data: {
            title: "Status",
            online: true,
        },
    });

    await bitsy.run();
</script>

A module script runs after the browser parses the document, unless you mark it async. Call run() once for the initial render. Use signals to update rendered bindings instead of calling run() again.

Bundle size#

The browser build is about 30.5 kB minified and 9.2 kB gzipped. It has no runtime dependencies.

Pre-render static output#

The included CLI captures HTML with Playwright so you can serve rendered content in the initial response. Add <meta name="bitsy-prerender" content="wait"> to the head of each page that needs to wait for BitsyJS. 

npx bitsy-prerender --src=./site --dist=./dist --clean

To use the CLI, install playwright and its Chromium browser separately. See Lifecycle for the flags and the ready signal it waits on.

Content security policy#

BitsyJS evaluates directive expressions with new Function. If your Content Security Policy blocks unsafe-eval, those expressions cannot run. Do not relax an existing policy just to enable them.

Use trusted expressions and HTML. BitsyJS does not sanitize inserted HTML. Read Security before accepting user-generated markup.
