Add interactivity to the HTML you render.

Use HTML attributes to bind data, show or hide content, and handle events. Use signals to update the parts of the page that change. No build step or virtual DOM required.

What it does

What you can build with BitsyJS

Bind values, render lists, and add interactive controls to the same page.

b-data

Data binding

Fill placeholders from the nearest data scope. If a key is missing, the placeholder stays visible.

Template

<ul>
  <li b-for="player of players">
    {player.name} - {player.score}
  </li>
</ul>

Output

  • Alpha10
  • Beta7
  • Gamma5

b-for / b-if

Loops and conditions

Repeat an element for each item with b-for. Use b-if to control which elements are visible.

b-for="player of players"

signal()

Reactive state with signals

Text, attributes, conditions, and loops that read a signal update when its value changes.

count.update(n => n + 1)

b-view

Fragments from your server

Fetch an HTML fragment and insert it into the page. A nested fragment's URL resolves relative to the fragment that contains it.

b-view src="./cart.html"

data-b-*

Events and forms

Bind DOM events in markup, validate fields on submit, and send forms with fetch without reloading the page.

data-b-validate="required|email"

The model

The model

Render once. Use signals for what changes.

During run(), BitsyJS reads your directives, applies bindings, and attaches event handlers. After that, bindings that read signals can update without another call to run().

  • {stat.value}{stat.label}

Reference

Directives at a glance

Most directives are HTML attributes. <b-view> and <b-container> are elements BitsyJS replaces during rendering.

No hydration required. BitsyJS works directly with the existing DOM. Render essential content on the server if it needs to be available without JavaScript.
Core directives and the scope each one reads
Directive What it does Reads from
b-data Creates a local scope for placeholders and nested directives. Constructor data and local values
b-for Repeats an element for each item and exposes loop metadata. Current scope
b-if Shows or hides an element with display: none. Current scope
b-view Fetches an HTML fragment and inserts it in place of the tag. Surrounding scope
b-container Groups markup and removes its wrapper unless the container has a condition. Does not create a scope
b-js Evaluates an expression and writes the result as HTML. Nearest scope
b-on:event Runs JavaScript when the specified DOM event fires. Current scope, $event, and $el
data-b-* Declarative events, remote templates, and form handling. Element attributes

Quick start

Render a scoreboard

Display a list of players and add a button that updates a counter.

01

Load the module

Import BitsyJS in a module script. This example uses a local copy of the browser build.

02

Pass in the data

Give the constructor a title, a list of players, and a signal for the counter.

03

Call run()

Once the markup is available, render the list and attach the click handler.

index.html 
<div b-data>
  <h2>{title}</h2>

  <ul>
    <li b-for="player of players">
      {player.name} - {player.score}
    </li>
  </ul>

  <button b-on:click="count.update(n => n + 1)">
    Count: <span b-js="count()">0</span>
  </button>
</div>
app.js 
import { BitsyJS, signal } from "./bitsy.min.js";

const count = signal(0);

const bitsy = new BitsyJS({
    data: {
        title: "Scoreboard",
        players: [
            { name: "Alpha", score: 10 },
            { name: "Beta", score: 7 },
        ],
        count,
    },
});

await bitsy.run();

Explore the features

Try live examples and see the markup and JavaScript behind them.

b-data

Data binding

Placeholders, dot paths, array indexes, attribute values, HTML values and missing keys.
b-for

Loops

Repeat a row for each item, use loop metadata, and rebuild the list when a signal changes.
b-if

Conditionals

Show or hide an element based on an expression, a signal, or the current loop item.
signal

Signals

Use signals, computed values, and effects in a counter and a to-do list.
b-on

Event bindings

Handle clicks, input, key presses, and form submissions from your markup.
data-b-event

Declarative events

Swap text or HTML, change classes, and undo changes after a delay without writing a listener.
remote

Remote data and templates

Fetch HTML or JSON and choose whether to replace or append to the target's content.
b-view

Fragments

Load reusable HTML, pass data into a fragment, and nest one fragment inside another.
b-container

Containers

Group elements for rendering without adding a wrapper to the final DOM.
forms

Forms

Submit a form with fetch, render the response, and optionally remove the form.
validation

Validation

Set field rules, show error messages, and block invalid submissions.
settings.tags

Custom tags

Rename directives without changing the defaults you still use.
